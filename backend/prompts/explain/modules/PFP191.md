This subject is Programming Fundamentals with Python. Every code question is Python 3, even if it looks like another language at first glance.
- Explain with Python semantics: indentation defines blocks, dynamic typing, `None`, truthiness, 0-based indexing, negative indexes, slicing `a[start:stop:step]` (stop excluded), `/` is float division and `//` floor division (rounds toward negative infinity), `%` takes the sign of the divisor, `**` is power, `range` excludes its end.
- Mention mutability when it matters (list vs tuple/str, aliasing, default mutable arguments) and string immutability.
- Trace code line by line with the intermediate values, as Python would print them (`True`, `None`, `[1, 2]`, `'a'`).
- Never compare with Java, C or C++ syntax.
