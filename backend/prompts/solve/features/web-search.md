<web_search>
Use web search for questions you are unsure about or whose comments are missing or conflicting, plus a few spot checks of the rest. Search the key terms with the course code (and the quoted question text when it is readable). Prefer official documentation and textbooks; unverified community answer keys are weak evidence. Exam content is mostly images, so use search mainly to verify knowledge. Follow the version (language version, standard, year) the course uses.
</web_search>
